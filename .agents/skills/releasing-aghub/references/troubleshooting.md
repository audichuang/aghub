# Release troubleshooting

A failed run leaves a **draft** — nothing shipped. The usual fix is
`gh run rerun <run-id> --repo audichuang/aghub --failed`, then resume with
`just release X.Y.Z --yes`.

| Symptom                                                                                                                                  | Cause                                                                                                                                                                                                                                                         | Fix                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| macOS `failed codesign … security import: failed to import keychain certificate`, or `APPLE_CERTIFICATE secret is not set`               | An `APPLE_*` secret is missing: unset secrets resolve to **empty strings**, so Tauri imports an empty cert                                                                                                                                                    | Re-set the secret from the 1Password `Agent` vault backup (`aghub …` items). Never put back `APPLE_SIGNING_IDENTITY: "-"` to get past it. `docs/history/release.md#macos-developer-id-signing`.                                                                                                                                                                                   |
| macOS "Verify macOS bundle signature…" fails on `Developer ID Application`, `stapler validate` or `spctl`                                | The app was not Developer-ID signed or not notarized: expired cert (2027-11-23), revoked API key, or notarization rejected                                                                                                                                    | Read the `Build Tauri` log for the notarytool status; renew the cert or API key and replace its secrets. `docs/history/release.md#macos-developer-id-signing`.                                                                                                                                                                                                                    |
| `Sign staged aghub-api (macOS)`, `Sign and notarize CLI (macOS)` or `Notarize and staple DMG (macOS)` fails (`scripts/ci-macos-sign.sh`) | Same secrets, signed outside tauri: `need APPLE_…` = a secret is empty; `TeamIdentifier is not …` / `no secure timestamp` = wrong cert in the `.p12`; `notarization status '…'` = the notary rejected the binary (its `notarytool log` is printed just above) | Fix the secret or cert as in the rows above and rerun the failed job. `docs/history/release.md#macos-developer-id-signing`.                                                                                                                                                                                                                                                       |
| A build job compiles ~600 crates (the Windows desktop job takes ~18 min); its "Rust Cache" step logs `No cache found`                    | The `release-<os>-<target>` key `ci.yml`'s `build` job saved on main differs: that job's cargo commands, matrix strings or non-empty `CARGO*`/`RUST*` env drifted from `release.yml`'s, or the entry was evicted                                              | Diff the "Cache Key" and "Environment considered" blocks of the two jobs' logs and realign them. An evicted entry comes back on the next main CI run. Why: `docs/history/tooling.md#release-build-speed`.                                                                                                                                                                         |
| `publish-homebrew` fails pushing to the tap                                                                                              | Missing/expired `HOMEBREW_TAP_TOKEN`                                                                                                                                                                                                                          | Reset the PAT secret and rerun the job; the rest of the release is unaffected.                                                                                                                                                                                                                                                                                                    |
| `publish-homebrew`: `no usable sha256 for release asset …`                                                                               | An expected asset is missing or has no digest                                                                                                                                                                                                                 | Check the asset list; rerun once the asset exists. Never hand-write a checksum.                                                                                                                                                                                                                                                                                                   |
| One `Build Desktop (<target>)` fails at `Uploading latest.json...` with `Not Found — update-a-release-asset`                             | The 3 desktop jobs read-modify-write the same `latest.json` (`includeUpdaterJson`) and one lost the race                                                                                                                                                      | `gh run rerun <run-id> --failed`, then `just release X.Y.Z --yes`.                                                                                                                                                                                                                                                                                                                |
| `publish`: `latest.json has no signed '<platform>' entry`, every build green                                                             | Same race, silent: a lost update dropped that platform's key                                                                                                                                                                                                  | Rerun that platform's `Build Desktop` job (`gh run rerun <run-id> --job <job-id>`), then rerun `publish`. Applies to hand-pushed tags and pre-releases too.                                                                                                                                                                                                                       |
| `just release`: `timed out waiting for ci.yml to go green on HEAD`                                                                       | The 3-OS cold compile outran the 40-min wait                                                                                                                                                                                                                  | Re-run `just release X.Y.Z --yes` once CI is green — HEAD is already pushed, so it tags at once (if main moved meanwhile, the re-run pushes and waits again, and ships those commits too).                                                                                                                                                                                        |
| `ci.yml` `test` on main fails on a test that passes locally / under `-p`, blocking `verify-ci`                                           | A test reading `dirs::home_dir()` raced a HOME/XDG-mutating test in the same process                                                                                                                                                                          | Hold the shared lock (`test_env_lock` in api, `env_lock` in core) in BOTH tests; `#[cfg(unix)]`-gate unix-only tests; canonicalize both sides for macOS `/var`→`/private`. Reproduce with plain `cargo test --workspace` (CI's nextest is one process per test, so the race only shows in-process).                                                                               |
| `just release`: `ci.yml for HEAD concluded 'failure'`, only `Rust Lint (ubuntu-latest)` red at `Cargo audit`                             | A RUSTSEC advisory published after the last green run; preflight runs no `cargo audit`, so nothing local caught it                                                                                                                                            | Run `cargo audit` locally. Bump each flagged crate in its OWN commit. A transitive copy no upgrade removes goes into `.cargo/audit.toml` with a reason and a lift condition — model: `docs/history/tooling.md#cargo-audit-ignores-the-updaters-zip-4`. A major bump can change behaviour quietly (zip 9 re-decoded legacy filenames): review it before re-running `just release`. |
| `just preflight` fails first: `'/…/.git' exists above the test temp dir`                                                                 | A stray `.git` in an ancestor of `$TMPDIR` (e.g. an empty `/tmp/.git`)                                                                                                                                                                                        | Remove it if stray (`rmdir` when empty), or `TMPDIR=/var/tmp just preflight` — TMPDIR must be OUTSIDE `/tmp`.                                                                                                                                                                                                                                                                     |

## Re-release a botched tag

Delete and retag only when the tagged commit itself must change. First confirm
nobody has it — a release can be minutes old and already pulled:

```bash
gh release view vX.Y.Z --repo audichuang/aghub \
  --json assets --jq '[.assets[].downloadCount] | add'   # 0 → deleting is safe
```

Non-zero, or already public: ship a new patch tag instead. Otherwise:

```bash
gh run cancel <run-id> --repo audichuang/aghub
gh release delete vX.Y.Z --repo audichuang/aghub --yes --cleanup-tag   # Release + remote tag
git tag -d vX.Y.Z
# commit the fix, pin the SHA, push main, wait for its CI to go green, then:
SHA=$(git rev-parse HEAD)
git tag vX.Y.Z "$SHA" && git push fork vX.Y.Z
```
